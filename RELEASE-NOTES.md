# HOTD4 Local Builder v1.3.2 for Windows

- The **SEGA startup logo** retains its original proportions in widescreen.
- The **escape gauge and shake prompt** stay aligned when a zombie grabs the player.
- **Justice’s health and cancel gauges** keep their frames and fills aligned during the Chapter 1 boss fight.

## Install or update

Extract **HOTD4-Local-Builder-v1.3.2.zip** and run **Setup.cmd** with your own complete, extracted **The House of the Dead 4 (Export), Rev A (DVP-0003A)** arcade dump. Both the original Rev A and the previously supported HD ELF work. Reuse your existing install folder to keep your settings, saves and trophies. Start the game from **Play HOTD4.exe**.

The ZIP contains the local builder and source. Setup builds the Windows executables on your PC. The ZIP contains no game assets or prebuilt game executables. **SHA256SUMS.txt** covers the ZIP. See the [README](https://github.com/davidptrssvea/HOTD4-recomp/blob/v1.3.2/README.md) for system requirements and the supported dump layouts.
